# Changelog

## [1.0.0] - 2026-10-06

- First release: shelf widget with Scan / Review / Clean, expanded
  review surface with per-category and per-item checkboxes (Safe cleanup
  vs Optional, review first), settings pane with Trash safety switch and
  default category toggles, and a HUD confirming freed space.
  Removed files go to the Trash; only emptying the Trash is permanent
  and is never pre-selected.
